## Cadastro de Parques de Teresina

Projeto desenvolvido em Python para praticar
Programação Orientada a Objetos (POO).

## Funcionalidades

- Cadastro de parques urbanos.
- Armazenamento de informações dos parques.
- Cálculo da relação entre a área do parque e a população do bairro.

## Tecnologias

- Python
- Programação Orientada a Objetos
- Git e GitHub
